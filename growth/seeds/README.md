# Seeds

One domain or URL per line. `leadhunt.py` crawls each one politely, reads robots.txt first, and keeps
only contact details the organisation publishes itself.

Two ways a seed gets in here:

1. someone on the team saw a business that obviously matches the profile;
2. `--search` returned it once, and it turned out to be a real buyer — pin it, so the list grows by
   judgement rather than by query volume.

Seeds are not a mailing list. They are candidate websites. A lead only exists once the site yields a
published address and the score clears the bar, and a human still reads it before anything is sent.
